# DDRX Vehicle Control Group Website

这是 DDRX 车辆控制小组 GitHub Pages 网站初稿，结构参考了 embodied-minds-lab.github.io 的简洁实验室主页风格。

## 本地预览

直接打开 `index.html` 即可预览。发布到 GitHub Pages 时，可以把本文件夹内容放到仓库根目录，或在仓库设置中选择对应发布目录。

## 当前页面

- `index.html`: 首页、研究方向、News
- `people.html`: 成员
- `publications.html`: 论文
- `projects.html`: 项目
- `contact.html`: 联系方式

## 已处理素材

- `assets/images/ddrx-logo-transparent.png`: 从 `../pic/DDRX-Head.jpg` 处理得到的透明底 DDRX 标志。
